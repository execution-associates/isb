# @execution-associates/isb-linux-x64

The static `isb` binary for Linux x64 (x86_64-unknown-linux-musl). It is an
optional dependency of [@execution-associates/isb](https://www.npmjs.com/package/@execution-associates/isb),
which finds it at `bin/isb`; install that package instead.

`bin/isb` is added at release time (.github/workflows/sdk-typescript.yml) and
is not in git.
